   ✓ GET  /productos                    → Listar (por defecto)
   ✓ GET  /productos?accion=formulario  → Mostrar formulario
   ✓ GET  /productos?accion=editar      → Editar (con id)
   ✓ GET  /productos?accion=eliminar    → Confirmar eliminación
   ✓ GET  /productos?accion=reporte     → Generar reporte
   ✓ POST /productos (accion=crear)     → Crear nuevo
   ✓ POST /productos (accion=actualizar) → Actualizar
   ✓ POST /productos (accion=eliminar)  → Eliminar confirmado

3. VALIDACIONES MULTICAPA

🚀 PASOS SIGUIENTES PARA EJECUTAR
═══════════════════════════════════════════════════════════════════════════════════

1. CONFIGURAR BASE DE DATOS
   → Ver archivo: database-setup.sql
   → Ejecutar en MySQL Workbench o línea de comandos

2. ACTUALIZAR CREDENCIALES
   → Editar: src/main/java/com/inventario/dao/ConexionDB.java
   → Usuario y contraseña de MySQL

3. COMPILAR PROYECTO
   → Ejecutar: gradle clean build

4. GENERAR WAR
   → Ejecutar: gradle war

5. DESPLEGAR EN TOMCAT
   → Copiar: build/libs/inventario-app.war → $CATALINA_HOME/webapps/
   → Acceder: http://localhost:8080/inventario-app/

DETALLES COMPLETOS EN: EJECUCION.md
